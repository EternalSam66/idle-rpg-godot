# 遺跡迴響（Echoes of the Ruin）— RPG 世界地圖系統設計 v2

## 1. 概述

取代原本的「文字區域列表」，改為一張**單一連續的 RPG 世界地圖**，使用 **CSS 繪製的 2D 地形景觀**，未探索區域以**迷霧**覆蓋。

### 核心改變

| 面向 | 舊系統 | v2 地圖系統 |
|---|---|---|
| 區域呈現 | 文字列表（入口/走廊/大廳…） | 連續 2D 世界地圖 |
| 未解鎖區域 | 灰色不可點文字 | 迷霧覆蓋，地形隱約可見 |
| 解鎖方式 | 累積金幣自動解鎖 | 手動點擊迷霧支付金幣解鎖 |
| 冒險者位置 | 文字提示 | 地圖上實體彩色圓點 |
| 探索反饋 | 純數字跳動 | 冒險者移動到目標 + 掉落提示 |

## 2. 地圖佈局

### 2.1 整體結構

- **單一連續地圖**，不分割為九宮格
- 比例約 **1.4:1** (寬 > 高)
- 以 CSS 絕對定位繪製所有地形元素
- 地圖背景為深綠色 (`#2a4a2a`)

### 2.2 地形元素（CSS 2D 繪製）

所有地形使用純 CSS 繪製（無圖片、無 emoji），延續 map-v2 風格：

| 元素 | CSS 實作 | 顏色 |
|---|---|---|
| **樹木** | `border` 三角樹冠 + `::after` 樹幹 | 樹冠: `#2d6a2d`~`#3a8a3a`, 樹幹: `#5a3a1a` |
| **山脈** | `border` 三角 + `::after` 雪頂 | 山體: `#5a5a4a`, 雪頂: `#6a6a5a` |
| **路徑** | 橫向/縱向矩形 | `#6a5a3a`, opacity 0.6 |
| **帳篷** | `border` 三角 + `::after` 內帳 | 帳布: `#8a6a3a`, 內帳: `#6a4a2a` |
| **廢墟牆壁** | 矩形 | `#6a5a4a` |
| **湖泊** | `border-radius` 橢圓 + 波浪弧線 | 湖水: `#1a3a6a`, 波浪: rgba(100,180,255,0.3) |
| **灌木叢** | `border-radius: 50%` 橢圓 | `#2a6a2a` |
| **岩石** | `border-radius` 圓角矩形 | `#7a7a6a` |
| **花朵** | `border-radius: 50%` 小圓 | 紅: `#c44`, 黃: `#ca4` |

### 2.3 區域命名與位置（第一張地圖）

| 區域 | 位置 | 地形 | 特徵 |
|---|---|---|---|
| 🏔️ 落日山丘 | 左上 (5%-25% x, 1%-22% y) | 山脈 | 初始解鎖，山腳道路入口 |
| 🪷 靜謐湖泊 | 中上 (52%-74% x, 4%-32% y) | 湖泊 | 需解鎖，湖畔有怪物🐍 |
| 🌲 幽暗森林 | 中右 (50%-80% x, 55%-90% y) | 深色森林 | 需解鎖，怪物🕷️聚集 |
| 🏘️ 風谷村 | 中左 (2%-22% x, 40%-60% y) | 營地/村莊 | 初始解鎖，有帳篷和寶箱 |
| 🏛️ 遠古遺跡 | 中下 (44%-62% x, 62%-82% y) | 廢墟 | 需解鎖，廢墟牆 + 寶箱 |

### 2.4 地區性文字標籤

每個區域在地圖上有小字標籤：
- 字體大小: 0.4rem
- 顏色: 依地形（湖區水藍 `#6af`、村莊暖色 `#ca8`、山區灰色 `#888`）
- 文字陰影: `0 1px 2px #000`

## 3. 迷霧系統

### 3.1 迷霧分區

地圖劃分為 **5 個迷霧區塊**（非對稱，配合地形）：

| 區塊 | 位置 | 狀態 |
|---|---|---|
| A | top:0, left:0, 寬 48%, 高 40% | 已解鎖（落日山丘 + 湖泊預覽） |
| B | top:40%, left:0, 寬 44%, 高 38% | 已解鎖（風谷村 + 遺跡入口） |
| C | top:0, left:48%, 寬 52%, 高 40% | 可解鎖（湖泊東岸 + 森林入口） |
| D | top:40%, left:44%, 寬 56%, 高 35% | 鎖住（森林深處 + 遺跡） |
| E | top:78%, left:0, 寬 100%, 高 22% | 鎖住（地圖底部，需先解鎖 D） |

### 3.2 迷霧視覺層級

| 狀態 | 視覺效果 |
|---|---|
| **已解鎖** | 完全透明，地形清晰可見 |
| **可解鎖（相鄰）** | 半透明黑色霧層 + 鎖圖示 + 金幣價格 + 點擊解鎖提示 |
| **鎖住（不相鄰）** | 高不透明黑色霧層 + 鎖圖示 + 「需先解鎖相鄰」提示 |

- 迷霧使用 `radial-gradient` 模擬自然霧氣擴散
- 可解鎖區 hover 時邊框泛金黃光暈
- 迷霧下地形景物**仍隱約可見**（森林、湖泊、遺跡輪廓）

### 3.3 解鎖規則

- **只能解鎖與已探索區域相鄰的迷霧區塊**
- 解鎖花費**金幣**
- 解鎖後迷霧淡出消失（transition 0.6s）
- 價格依區域位置遞增：

| 區塊 | 解鎖價格 |
|---|---|
| C（第一層） | 600🪙 |
| D（第二層，需 C） | 1200🪙 |
| E（底部，需 D） | 2000🪙 |

### 3.4 解鎖互動

- 迷霧區塊為 `pointer-events: auto`
- 點擊迷霧區 → 檢查金幣是否足夠 → 扣除金幣 → 迷霧淡出
- hover 時迷霧變淡，顯示下方地形輪廓

## 4. 冒險者視覺化

### 4.1 地圖上的冒險者

每個冒險者以**彩色圓點**顯示在地圖上：

| 職業 | 顏色 | CSS class |
|---|---|---|
| 戰士 | 紅色 `#e74c3c` | `.adv-warrior` |
| 遊俠 | 綠色 `#2ecc71` | `.adv-ranger` |
| 法師 | 紫色 `#9b59b6` | `.adv-mage` |
| 牧師 | 金色 `#f1c40f` | `.adv-priest` |

- 圓點大小: 12px
- 外框: 2px solid white
- 發光動畫: `pulse` (1.5s ease-in-out infinite)
- 對應職業特定光暈色

### 4.2 移動動畫

- 冒險者被派去探索時顯示 **方向箭頭**（金色 ▶）
- 箭頭朝目標方向，帶 bounce 動畫
- 箭頭位置在冒險者圓點與目標之間

### 4.3 探索目標標記

- 探索點產生後，地圖上隨機一個已解鎖位置出現**閃爍標記**
- 最近的冒險者自動前往（顯示箭頭）
- 抵達後觸發掉落 + 標記消失

## 5. 探索條（點擊核心）

### 5.1 外觀

- 位於地圖下方
- 左側圖示: 🏛️
- 進度條: 白→金→橘漸層
- 右側百分比 + 提示文字
- 背景深色卡片，與整體 UI 一致

### 5.2 機制

- 每次點擊累積探索條進度
- 探索條滿 → 產生 **1 個探索點**
- 探索點自動指派給距離最近的冒險者
- 冒險者前往隨機已解鎖地圖位置
- 抵達後觸發掉落

### 5.3 掉落表

| 掉落物 | 機率 | 數量範圍 |
|---|---|---|
| 🪙 金幣 | 70% | 10-50 |
| 💎 遺物碎片 | 20% | 1-3 |
| ⚔️ 怪物遭遇 | 10% | 戰鬥獎勵（金幣+碎片） |

## 6. 怪物與寶箱

### 6.1 怪物

- 在地圖上以符號顯示（🐗🐺🕷️）
- 位置固定（每個區域 1-2 個）
- 帶紅色光暈 `drop-shadow`
- 探索遇到時觸發戰鬥事件（掉落更多獎勵）

### 6.2 寶箱

- 以 🧰 顯示
- 帶金色光暈 `drop-shadow`
- 低機率但高獎勵
- 探索抵達寶箱位置時必掉 **遺物碎片**

---

## 7. 地圖完成與地圖切換

### 7.1 完成條件

- 所有迷霧區塊解鎖
- 不需要探索每一寸土地，只需解鎖所有區塊

### 7.2 完成獎勵

- 獲得 **1 個拼圖碎片**
- 解鎖「前往下一張地圖」按鈕

### 7.3 拼圖機制

- 每張地圖完成給 1 片拼圖
- 收集 N 片拼圖解鎖更深層遺跡（N 待定，建議 3-5）
- 拼圖收集進度顯示在地圖角落

### 7.4 下一張地圖

- 新地圖有不同主題和配置
- 冒險者和資源保留
- 所有冒險者移回新地圖入口區域
- 新地圖需要重新解鎖迷霧

| 冒險者 | 解鎖條件 |
|---|---|
| 戰士 | 初始擁有 |
| 遊俠 | 初始擁有 |
| 法師 | 花費 5,000🪙 |

### 8.2 區域進度替代

每解鎖一個地圖區塊，所有冒險者獲得產出加成（取代原本的區域光環）。

## 9. 技術備註

### 9.1 CSS 優先

- 所有地形使用純 CSS（border、clip-path、border-radius）
- 不使用圖片、SVG 或 canvas
- 迷霧使用 CSS `radial-gradient` 疊加
- 動畫使用 CSS `@keyframes`

### 9.2 狀態管理

GameState 新增：
```js
{
  maps: {
    currentMap: 0,
    maps: [
      {
        id: 'ruin-entrance',
        name: '遺跡入口',
        fogZones: [
          { id: 'A', unlocked: true },
          { id: 'B', unlocked: true },
          { id: 'C', unlocked: false, cost: 600, adjacentTo: ['A','B'] },
          { id: 'D', unlocked: false, cost: 1200, adjacentTo: ['C'] },
          { id: 'E', unlocked: false, cost: 2000, adjacentTo: ['D'] },
        ],
        puzzlePiece: false
      }
    ],
    explorerProgress: 0,  // 0-100
    explorerMax: 100,
  }
}
```

### 9.3 離線進度

離線時：
- 探索條不累積（需玩家點擊）
- 金幣和碎片照常產出
- 冒險者位置不變
