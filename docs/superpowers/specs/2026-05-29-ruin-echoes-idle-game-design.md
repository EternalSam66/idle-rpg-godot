# 遺跡迴響（Echoes of the Ruin）— 放置增量遊戲設計文件

## 1. 遊戲概念

### 一句話
你是一位公會會長，招募冒險者探索不斷重生的遠古遺跡。冒險者自動賺取資源，你投資升級來解鎖更強的英雄和區域——每次遺跡重組（轉生），你的「迴響之力」永久變強。

### 參考遊戲（12+）
Cookie Clicker、Adventure Capitalist、Clicker Heroes、Egg Inc.、Idle Miner Tycoon、Realm Grinder、Antimatter Dimensions、Kittens Game、NGU Idle、Universal Paperclips、Swarm Sim、Idle Champions of the Forgotten Realms

### 核心支柱
- **增量成長**：數字一直跳、升級一直買、解鎖一直開
- **冒險者養成**：銅→銀→金→傳奇，稀有度進化，外觀變化
- **區域探索**：6 個風格迥異的遺跡區域，每個有獨特產出和升級（可擴充）

## 2. 核心循環

```
點擊遺跡 → 獲得探索能量
    ↓
冒險者自動探索 → 產生金幣 + 碎片
    ↓
購買升級 → 訓練場／裝備／補給
    ↓
金幣達標 → 解鎖新冒險者 / 新區域
    ↓
到達瓶頸 → 轉生（遺跡重組）→ 獲得迴響石（永久倍率）
    ↓
變得更強，重新出發
```

## 3. 資源系統（4 種）

| 資源 | 用途 | 取得方式 |
|---|---|---|
| 金幣 | 購買所有升級、訓練冒險者 | 冒險者自動產生 + 點擊遺跡 |
| 遺物碎片 | 解鎖新冒險者、稀有度進化 | 區域探索掉落、轉生獎勵 |
| 探索能量 | 加速冒險者效率（短暫爆發） | 點擊遺跡產生 |
| 迴響石 | 轉生後永久產出倍率 | 每次轉生獲得，依累積金幣總量計算 |

## 4. 冒險者系統

### 屬性
- **產出**：每秒多少金幣（主要的成長數字）
- **稀有度**：銅→銀→金→傳奇，影響產出倍率與卡片外觀
- **職業**：戰士 / 法師 / 遊俠 / 牧師

### 羈絆系統（唯一策略層）
特定職業組合觸發被動加成：
- 戰士 + 牧師 → 全隊 +30% 產出
- 法師 + 遊俠 → 探索能量恢復 +50%
- 戰士 + 法師 + 遊俠 + 牧師（全員）→ 全隊 +100% 產出

稀有度提升只影響數字和卡片框色，不增加策略複雜度。

## 5. 區域進度

| 區域 | 解鎖條件 | 特色 |
|---|---|---|
| 遺跡入口 | 初始解鎖 | 基礎金幣產出，第一個冒險者 |
| 荊棘走廊 | 累計 1K 金幣 | 解鎖遊俠，產出速度升級 |
| 石像鬼大廳 | 累計 10K 金幣 | 解鎖戰士，產出倍率升級 |
| 迴響深淵 | 累計 100K 金幣 | 解鎖法師，碎片掉落增加 |
| 聖光禮拜堂 | 累計 1M 金幣 | 解鎖牧師，羈絆效果翻倍 |
| 遠古王座 | 累計 10M 金幣 | 最終區域，大幅提升轉生獎勵 |

每解鎖一個區域，所有冒險者產出獲得區域光環加成。保留往後版本新增區域的擴充能力。

## 6. 轉生（遺跡重組）

- **觸發時機**：玩家到達瓶頸（所有升級買完，產出趨緩）
- **重置內容**：金幣、碎片、區域進度、冒險者等級
- **保留內容**：迴響石（永久產出倍率）
- **迴響石計算**：基於本次累積總金幣量，開根號後給予合理遞增
- 保留新增轉生層級（如「覺醒」、「昇華」）的擴充能力

## 8. 技術架構

| 層級 | 選擇 | 原因 |
|---|---|---|
| 前端 | 純 HTML + CSS + JavaScript（或 React） | 單頁應用，不需路由 |
| 狀態管理 | 自訂 GameState 物件 + localStorage | 自動存檔 |
| 離線進度 | `Date.now()` 計算離線時間 | 載入時模擬離期產出 |
| 打包工具 | Vite | 快速開發、輕量 |
| 部署 | 靜態網站（GitHub Pages / Netlify） | 零後端、零成本 |

### 離線進度規則
- 每次 tick 保存 `timestamp` 到 localStorage
- 重新載入時計算 (當前時間 - 上次時間) = 離線秒數
- 最多計算 24 小時（防止時間操縱）
- 離線效率 × 60%（鼓勵上線，但不懲罰離線）

### 遊戲循環
```
requestAnimationFrame / setInterval(1000ms)
  → game.tick()
    → 每個冒險者: 產出 += base × multiplier
    → 資源更新 → 檢查解鎖 → 更新 UI → 保存
```
